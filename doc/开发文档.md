## 安装扩展（VSIX）

在 VS Code / Cursor 中通过本地 `.vsix` 安装本扩展（文件形如 `combuilder-0.1.0.vsix`）。

### 1. 图形界面安装（VS Code / Cursor）

1. 打开 **VS Code** 或 **Cursor**
2. `Cmd+Shift+P`（Windows / Linux：`Ctrl+Shift+P`）打开命令面板
3. 输入并选择：**Extensions: Install from VSIX...**（从 VSIX 安装扩展…）
4. 选中 `combuilder-*.vsix`
5. 安装完成后按提示 **Reload Window**（重新加载窗口）

### 2. 命令行安装

**VS Code：**

```bash
code --install-extension ./combuilder-0.1.0.vsix
```

**Cursor：**

```bash
cursor --install-extension ./combuilder-0.1.0.vsix
```

路径按实际 `.vsix` 文件名调整。装好后同样需要 **Reload Window**。

### 3. 验证

- 扩展列表中能看到 **Combuilder**
- 打开工程中带 UI 的 JSON（如 `examples/src/ui/activities/*.json`），可用自定义编辑器预览
- 侧栏 / 面板中出现「固件编译」「真机调试」等视图

### 4. 更新与卸载

- **更新**：再用「Install from VSIX」或命令行安装新版本 `.vsix`（会覆盖旧版）
- **卸载**：扩展视图中找到 **Combuilder** → 卸载 / Uninstall

## 0. 公共约定

### 0.1 尺寸取值

| 值 | 含义 |
|----|------|
| `match_parent` | 占满父容器对应边 |
| `wrap_content` | 按内容收缩 |

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `id` | string | | 控件唯一 ID，C 代码里 `findView` / 焦点 / Adapter 用 |
| `width` | size | `wrap_content` | 宽 |
| `height` | size | `wrap_content` | 高 |
| `weight` | number | | 比例权重（仅父为 column/row/frame） |
| `padding` | number 或 `[上,右,下,左]` | | 内边距 |
| `margin` | number 或 `[上,右,下,左]` | | 外边距 |
| `radius` | number | | 圆角 |
| `background` | color `#RRGGBB` | | 背景色 |
| `visible` | bool | `true` | 是否可见 |

### 0.3 焦点属性

| 属性 | 类型 | 说明 |

### 0.5 相对布局子项属性（父为 `relative` 时）

| 属性 | 类型 | 说明 |

| `align_top_id` | string | 顶对齐到 id |

### 0.6 C 代码：找控件


## 1. 纵向布局 `column`

### 是干什么的

子控件**从上到下**排列的弹性容器，适合整页根布局、表单纵向堆叠。

### JSON

```json
{
  "type": "column",
  "id": "root",
  "width": "match_parent",
  "height": "match_parent",
  "background": "#0f172a",
  "padding": 16,
  "alignH": "center",
  "alignV": "center",
  "gap": 8,
  "scrollable": false,
  "scrollbarMode": "off",
  "children": [
    { "type": "text", "id": "t1", "text": "标题", "color": "#ffffff", "fontSize": 18 }
  ]
}
```

### C 代码

```cpp
/* XxxActivity.h / .cpp —— Activity 名与 app.json 一致 */
#include "activity_base.h"
#include "xxx_activity_ui.h"   /* 编译工程后生成 */

class XxxActivity : public Activity {
public:
    void buildUi(lv_obj_t * screen) override;
    void onCreate() override;
};

void XxxActivity::buildUi(lv_obj_t * screen) {
    ui_XxxActivity_build(screen);   /* 根据 JSON 生成整棵树 */
}

void XxxActivity::onCreate() {
    /* 运行时改子控件：用 JSON 里的 id */
    lv_obj_t * t1 = findView("t1");
    if (t1) {
        lv_label_set_text(t1, "新标题");
        lv_obj_set_style_text_color(t1, lv_color_hex(0xffffff), LV_PART_MAIN);
    }

    /* 隐藏 / 显示整块布局 */
    lv_obj_t * root = findView("root");
    if (root) lv_obj_add_flag(root, LV_OBJ_FLAG_HIDDEN);      /* 隐藏 */
    if (root) lv_obj_clear_flag(root, LV_OBJ_FLAG_HIDDEN);    /* 显示 */
}
```

### 属性表

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `type` | `"column"` | | 组件类型 |
| `id` | string | | 控件 ID |
| `width` | size | `wrap_content` | 宽 |
| `height` | size | `wrap_content` | 高 |
| `weight` | number | | 父为 flex 时的比例 |
| `padding` | box | | 内边距 |
| `margin` | box | | 外边距 |
| `radius` | number | | 圆角 |
| `background` | color | | 背景 |
| `visible` | bool | `true` | 可见 |
| `alignH` | `start`/`center`/`end` | | 子项水平对齐 |
| `alignV` | `start`/`center`/`end` | | 子项垂直对齐 |
| `gap` | number | | 子项间距（px） |
| `scrollable` | bool | `false` | 可滚动 |
| `scrollbarMode` | select | `off` | 滚动条模式 |
| `children` | array | | 子节点 |

## 2. 横向布局 `row`

### 是干什么的

子控件**从左到右**排列，适合工具栏、一行多个按钮。

### JSON

```json
{
  "type": "row",
  "id": "toolbar",
  "width": "match_parent",
  "height": "wrap_content",
  "alignV": "center",
  "gap": 12,
  "children": [
    { "type": "button", "id": "btn_a", "text": "A", "focusable": true },
    { "type": "button", "id": "btn_b", "text": "B", "focusable": true }
  ]
}
```

### C 代码

```cpp
void XxxActivity::buildUi(lv_obj_t * screen) {
    ui_XxxActivity_build(screen);
}

void XxxActivity::onCreate() {
    /* 按键在 A / B 间跳转焦点，或直接改按钮文字 */
    lv_obj_t * a = findView("btn_a");
    lv_obj_t * b = findView("btn_b");
    if (a) {
        lv_obj_t * lab = lv_obj_get_child(a, 0); /* 按钮内 label，视生成结构而定 */
        if (lab) lv_label_set_text(lab, "确定");
    }
    bindKey("boot", [this]() {
        /* 确认当前焦点按钮 */
        confirmFocused("click");
    });
    (void)b;
}
```

### 属性表

与 [column](#1-纵向布局-column) 相同，仅 `type` 为 `"row"`。

## 3. 层叠容器 `frame`

### 是干什么的

子控件叠在同一区域（类似 Android FrameLayout），用于角标叠在图片上等。

### JSON

```json
{
  "type": "frame",
  "id": "banner",
  "width": "match_parent",
  "height": 120,
  "children": [
    { "type": "image", "id": "bg", "src": "images/banner.bin", "width": "match_parent", "height": "match_parent" },
    { "type": "text", "id": "badge", "text": "NEW", "color": "#ff0" }
  ]
}
```

```cpp
void XxxActivity::buildUi(lv_obj_t * screen) {
    ui_XxxActivity_build(screen);
}

void XxxActivity::onCreate() {
    lv_obj_t * badge = findView("badge");

    /* 隐藏角标 */

}
```

### 属性表

与 column 相同，仅 `type` 为 `"frame"`。

## 4. 相对布局 `relative`

### 是干什么的

子控件用相对约束定位（贴父、在某控件上下左右），适合「标题固定 + 下方列表拉满」。

### JSON

```json
{
  "type": "relative",
  "id": "root",
  "width": "match_parent",
  "height": "match_parent",
  "background": "#1e1e1e",
  "padding": 2,
  "children": [
    {
      "type": "text",
      "id": "title",
      "text": "标题",
      "fontSize": 18,
      "color": "#FFFFFF",
      "align_parent": "top"
    },
    {
      "type": "list",
      "id": "list_1",
      "top_id": "title",
      "bottom_id": "0",
      "height": "0",
      "width": "match_parent",
      "itemHeight": 40
    }
  ]
}
```

### C 代码

```cpp
void ListActivity::buildUi(lv_obj_t * screen) {
    ui_ListActivity_build(screen);  /* relative 约束已编进生成代码 */
}

void ListActivity::onCreate() {
    lv_obj_t * title = findView("title");
    if (title) lv_label_set_text(title, "列表页");

    /* 列表数据见第 10 / 11 章 setAdapter */
    setAdapter("list_1", &adapter_);
}
```

相对约束（`top_id` / `align_parent` 等）只在 JSON → 编译期生效，运行时一般不改约束，只改子控件内容。

### 属性表（容器自身）

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `type` | `"relative"` | | |
| `id` | string | | |
| `width` / `height` | size | | |
| `weight` | number | | 父为 flex 时 |
| `padding` / `margin` | box | | |
| `radius` / `background` / `visible` | | | 外观 |
| `scrollable` / `scrollbarMode` | | | 滚动 |
| `children` | array | | 子节点（子节点还可带 [0.5 相对约束](#05-相对布局子项属性父为-relative-时)） |

## 6. 按钮 `button`

### 是干什么的

可点击/可聚焦的按钮，带文字。

### JSON

```json
{
  "type": "button",
  "id": "btn_go",
  "text": "进入列表",
  "fontSize": 16,
  "color": "#ffffff",
  "background": "#2563eb",
  "padding": [8, 16, 8, 16],
  "focusable": true,
  "focusDefault": true,
  "action": "navigate:ListActivity"
}
```

> `action` **预览生效**；真机请在 C++ 里写等价逻辑。

### C 代码

```cpp
#include "navigate.h"
#include "alert.h"

void SettingsActivity::buildUi(lv_obj_t * screen) {
    ui_SettingsActivity_build(screen);
}

void SettingsActivity::onCreate() {
    /* JSON 里的 action 仅预览有效；真机用按键或焦点确认 */
    bindKey("boot", []() { navigateTo("ListActivity"); });

    /* 运行时改按钮文案（按钮内通常是 label 子对象） */
    lv_obj_t * btn = findView("btn_go");
    if (btn) {
        lv_obj_t * lab = lv_obj_get_child(btn, 0);
        if (lab) lv_label_set_text(lab, "去列表");
    }
}
```

## 9. 画布 `canvas`

### 是干什么的

空白可绘制区域，适合自定义绘图。

### JSON

```json
{
  "type": "canvas",
  "id": "plot",
  "width": "match_parent",
  "height": 100,
  "background": "#111111"
}
```

### C 代码

```cpp
#include "lvgl.h"

static void on_plot_draw(lv_event_t * e) {
    lv_obj_t * obj = (lv_obj_t *)lv_event_get_target(e);
    lv_layer_t * layer = lv_event_get_layer(e);
    if (!obj || !layer) return;

    lv_draw_rect_dsc_t dsc;
    lv_draw_rect_dsc_init(&dsc);
    dsc.bg_color = lv_color_hex(0x22c55e);
    dsc.bg_opa = LV_OPA_COVER;
    lv_area_t a;
    lv_obj_get_coords(obj, &a);
    /* 在控件区域内画一块示例矩形（具体 draw API 随 LVGL 版本略有差异） */
    lv_area_t r = a;
    r.x2 = r.x1 + 40;
    r.y2 = r.y1 + 40;
    lv_draw_rect(layer, &dsc, &r);
}

void XxxActivity::onCreate() {
    lv_obj_t * c = findView("plot");
    if (!c) return;
```

## 10. 列表 `list`

### 是干什么的

**虚拟列表**：只渲染可见行，数据由 `UiListAdapter` 提供。子节点里放一条 **item 模版**（`role: "itemTemplate"`），运行时按模版刷每一行。条目外观（选中/未选中）写在模版的 `focusStyle` 里。

### JSON

```json
{
  "type": "list",
  "id": "list_main",
  "width": "match_parent",
  "height": "match_parent",
  "background": "#111111",
  "itemHeight": 40,
  "focusable": true,
  "scrollable": true,
  "scrollbarMode": "auto",
  "children": [
    {
      "type": "text",
      "id": "text_0",
      "role": "itemTemplate",
      "text": "Item",
      "width": "match_parent",
      "height": 40,
      "color": "#ffffff",
      "fontSize": 14,
      "focusStyle": {
        "focused": {
          "background": "#2563eb",
          "color": "#ffffff"
        },
        "blurred": {
          "background": "#1a1a1a",
          "color": "#e5e5e5"
        }
      }
    }
  ]
}
```

## 21. 线程 / Service 开发

### 是干什么的

在 **独立 FreeRTOS 任务**里跑阻塞 IO / 计算，避免卡住 UI（LVGL）线程。  
`IoService` 是内置线程池；也可自定义 `Service` 子类。

**注意：没有 `runOnUiThread`。** 回 UI 请用 `lv_async_call` 或 `lv_timer_create`。

### JSON（`app.json` 注册）

```json
"services": [
  {
    "name": "IoService",
    "driver_class": "IoService",
    "driver_source": "app/services/io_service_app.cpp",
    "priority": -1,
    "stack_size": 8192,
    "workers": 2
  }
]
```

自定义服务示例字段相同：`name` / `driver_class` / `driver_source` / `priority` / `stack_size`；（`workers` 仅 IoService 池使用）。

### C 代码 — 使用 IoService

```cpp
#include "io_service.h"
#include "lvgl.h"

// Application::onCreate 或 Activity 内：
auto * io = getApplication()->services().getAs<IoService>("IoService");
// 或 App 内：services().getAs<IoService>("IoService");

io->post([]() {
    // 在 IO 线程：可读文件、网络等，禁止直接操作 LVGL
    // ...
    // 回到 UI 线程改界面：
    lv_async_call([](void * user) {
        (void)user;
        // 此处可 findView / lv_label_set_text
    }, nullptr);
});
```

示例：`examples/src/app/application.cpp`。

### C 代码 — 自定义 Service

```cpp
// 编译器会按 app.json 生成桩，形态类似：
class SensorService : public Service {
public:
    SensorService()
        : Service(ServiceConfig{"SensorService", /*priority*/ -1, /*stack*/ 4096u, /*core*/ -1}) {}

    void onStart() override {
        // 启动后逻辑；也可 post 循环任务
        post([this]() { /* 后台工作 */ });
    }

    void onStop() override {}
};
```

投递：

```cpp
services().post("SensorService", []() { /* ... */ });
// 或
auto * s = services().getAs<SensorService>("SensorService");
s->post(&SensorService::pollOnce, s);
```

## 23. 视频开发

### 是干什么的

框架**尚未内置** `type: "video"` 组件与播放器。当前做法：

1. 用 **`canvas` 或 `image`** 当「视频画面」控件（JSON 里摆好位置/尺寸）；
2. 在 **IoService / 自建 Service** 里取流、解码；
3. 用 **`lv_async_call`** 回到 UI 线程，把一帧 RGB565（或 JPEG→解码后）刷到该控件。

常见取流来源：

| 来源 | 怎么拿帧 | 说明 |
|------|----------|------|
| 板载摄像头 | `esp_camera_fb_get()` | OV2640 等，ESP-IDF `esp_camera` |
| HTTP MJPEG | `esp_http_client` 读 multipart | 监控/网页摄像头常见 |
| 本地文件 | 读 SD/flash 上的 MJPEG/逐帧 JPEG | 无 RTSP 管线时的简易方案 |
| RTSP/H.264 | 需自接解码库 | 本框架未集成，内存与算力要求高 |

> 下列 JSON 为**推荐布局约定**（编辑器可按 `canvas`/`image` 编辑）。`src` / `fps` 等业务字段可写在 JSON 里自行读取，或只写在 C++ 常量中。

#### 1）Activity：拿控件 + 启动拉流

```cpp
#include <atomic>

private:
    lv_obj_t * surface_ = nullptr;
    lv_obj_t * status_ = nullptr;
    std::atomic<bool> running_{false};

    lv_image_dsc_t frame_dsc_{};
```

```cpp
/* video.cpp（骨架） */
#include "video.h"
#include "video_ui.h"
#include "io_service.h"
#include <cstdio>
#include <cstring>

void VideoActivity::buildUi(lv_obj_t * screen) {
    ui_VideoActivity_build(screen);
}

void VideoActivity::onCreate() {
    surface_ = findView("video_surface");
    status_ = findView("video_status");
    running_.store(true);
    setStatus("启动取流…");
    startStreamLoop();
}

void VideoActivity::onDestroy() {
    running_.store(false);
    /* 等待 Io 任务退出后，再 free frame_buf_ */
}

void VideoActivity::setStatus(const char * s) {
    if (status_ && s) lv_label_set_text(status_, s);
}

void VideoActivity::presentRgb565(const uint16_t * pixels, int w, int h) {
    if (!surface_ || !pixels || w <= 0 || h <= 0) return;

    /* 必须在 LVGL 线程执行；由 lv_async_call 调进来 */
    const size_t bytes = (size_t)w * (size_t)h * 2;
    if (!frame_buf_) {
        frame_buf_ = (uint16_t *)lv_malloc(bytes);
        if (!frame_buf_) return;
    }
    std::memcpy(frame_buf_, pixels, bytes);

    frame_dsc_.header.magic = LV_IMAGE_HEADER_MAGIC;
    frame_dsc_.header.cf = LV_COLOR_FORMAT_RGB565;
    frame_dsc_.header.w = w;
    frame_dsc_.header.h = h;
    frame_dsc_.data_size = bytes;
    frame_dsc_.data = (const uint8_t *)frame_buf_;

    /* surface 若是 image： */
    lv_image_set_src(surface_, &frame_dsc_);
    /* 若是 canvas：改用 lv_canvas_set_buffer / copy_buf（按你生成的控件类型选一种） */
    lv_obj_invalidate(surface_);
}

void VideoActivity::startStreamLoop() {
    auto * app = getApplication();
    auto * io = app ? app->services().getAs<IoService>("IoService") : nullptr;
    if (!io) {
        setStatus("无 IoService");
        return;
    }

    /* 把 this 交给后台；后台只取流，刷新走 lv_async_call */
    io->post([this]() {
        /* 任选下面「摄像头」或「HTTP MJPEG」实现 */
        this->setStatus("取流中"); /* 注意：label 非线程安全，正式应 lv_async_call 改文案 */
        /* run_camera_loop(this); */
        /* run_mjpeg_http_loop(this, "http://192.168.1.100:81/stream"); */
    });
}
```

**把帧安全刷到 UI（后台线程每拿到一帧调用）：**

```cpp
struct FrameMsg {
    VideoActivity * self;
    uint16_t * copy; /* 后台 malloc 的一帧，UI 用完 free */
    int w, h;
};

static void ui_present_cb(void * user) {
    auto * m = static_cast<FrameMsg *>(user);
    if (m && m->self && m->copy) {
        m->self->presentRgb565(m->copy, m->w, m->h);
        free(m->copy);
    }
    delete m;
}

/* 在 IoService 线程里： */
void push_frame_to_ui(VideoActivity * self, const uint16_t * src, int w, int h) {
    size_t n = (size_t)w * (size_t)h;
    auto * copy = (uint16_t *)malloc(n * 2);
    if (!copy) return;
    memcpy(copy, src, n * 2);

    auto * m = new FrameMsg{self, copy, w, h};
    if (lv_async_call(ui_present_cb, m) != LV_RESULT_OK) {
        free(copy);
        delete m;
    }
}
```

#### 2）怎么获取视频流 — 板载摄像头（`esp_camera`）

依赖：ESP-IDF 组件 `esp32-camera`，引脚按板型配置。

```cpp
#include "esp_camera.h"

static camera_config_t make_cam_cfg() {
    camera_config_t c = {};
    c.pin_pwdn = -1; /* 按原理图填写 */
    c.pin_reset = -1;
    c.pin_xclk = /* ... */;
    /* pin_sccb_sda/scl, pin_d0..d7, pin_vsync, pin_href, pin_pclk ... */
    c.xclk_freq_hz = 20000000;
    c.pixel_format = PIXFORMAT_RGB565;   /* 直接给 LVGL；也可用 JPEG 再解码 */
    c.frame_size = FRAMESIZE_QVGA;       /* 320x240，按屏改 */
    c.fb_count = 2;
    c.grab_mode = CAMERA_GRAB_LATEST;
    return c;
}

void run_camera_loop(VideoActivity * self) {
    if (esp_camera_init(&make_cam_cfg()) != ESP_OK) {
        /* lv_async_call 提示失败 */
        return;
    }

    while (self /* && self->running() */) {
        camera_fb_t * fb = esp_camera_fb_get();
        if (!fb) continue;

        if (fb->format == PIXFORMAT_RGB565) {
            push_frame_to_ui(self,
                reinterpret_cast<const uint16_t *>(fb->buf),
                fb->width, fb->height);
        } else if (fb->format == PIXFORMAT_JPEG) {
            /* 用 esp_jpeg / tjpgd 解成 RGB565 后再 push_frame_to_ui */
        }

        esp_camera_fb_return(fb);
        vTaskDelay(pdMS_TO_TICKS(10)); /* 控帧率，避免打满 CPU */
    }
    esp_camera_deinit();
}
```

要点：

1. `esp_camera_fb_get()` → 拿到一帧；
2. `esp_camera_fb_return(fb)` → **必须归还**，否则很快无缓冲；
3. 格式优先 `RGB565`，少一次解码；JPEG 省带宽但要解码时间；
4. 取流只在 Service 线程，**禁止**在回调里直接 `lv_image_set_src`。

#### 3）怎么获取视频流 — HTTP MJPEG

许多 IP 摄像头 / ESP 开源固件提供：

`http://<ip>/stream` 或 `http://<ip>:81/stream`  
（`Content-Type: multipart/x-mixed-replace; boundary=...`）

```cpp
#include "esp_http_client.h"
#include "esp_heap_caps.h"

/* 从 HTTP 响应体里拆 JPEG 帧（简化示意） */
static bool read_one_jpeg(esp_http_client_handle_t cli,
                          uint8_t * buf, size_t cap, size_t * out_len) {
    /* 1) 读到 JPEG SOI 0xFFD8
     * 2) 一直读到 EOI 0xFFD9
     * 3) *out_len = 整帧长度
     * 生产代码请按 boundary 解析 multipart
     */
    (void)cli; (void)buf; (void)cap; (void)out_len;
    return false;
}

void run_mjpeg_http_loop(VideoActivity * self, const char * url) {
    esp_http_client_config_t cfg = {};
    cfg.url = url;
    cfg.timeout_ms = 10000;
    cfg.buffer_size = 4096;

    esp_http_client_handle_t cli = esp_http_client_init(&cfg);
    if (!cli || esp_http_client_open(cli, 0) != ESP_OK) return;

    const size_t cap = 64 * 1024;
    uint8_t * jpeg = (uint8_t *)heap_caps_malloc(cap, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT);
    if (!jpeg) jpeg = (uint8_t *)malloc(cap);

    while (self /* && running */) {
        size_t len = 0;
        if (!read_one_jpeg(cli, jpeg, cap, &len) || len == 0) {
            vTaskDelay(pdMS_TO_TICKS(20));
            continue;
        }

        /* JPEG → RGB565：可用 esp_jpeg_dec / LVGL tjpgd 等
         * decode_jpeg_to_rgb565(jpeg, len, rgb, &w, &h);
         * push_frame_to_ui(self, rgb, w, h);
         */
        (void)len;
    }

    free(jpeg);
    esp_http_client_close(cli);
    esp_http_client_cleanup(cli);
}
```

要点：

1. 先 `WiFi` 连上（`app.json` → `network` + `syncNtp`/既有联网逻辑）；
2. HTTP 客户端读流，按 **multipart boundary** 或 **JPEG SOI/EOI** 切帧；
3. 每帧解码为 RGB565 → `push_frame_to_ui`；
4. 缓冲优先放 **PSRAM**（`MALLOC_CAP_SPIRAM`）。

#### 4）数据流（记住这一条）

```
[摄像头 / HTTP / 文件]
        │  IoService 线程：取帧 + 解码
        ▼
  RGB565 帧缓冲（可双缓冲）
        │  lv_async_call
        ▼
  UI 线程：lv_image_set_src / canvas 刷新
        │
        ▼
  JSON 里的 video_surface 控件
```
